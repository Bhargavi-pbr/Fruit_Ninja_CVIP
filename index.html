Classical CVIP Pipeline Inspection Studio

This real-time inspector visualizes the classical Computer Vision pipeline operating on webcam frames. It executes color-space skin segmentation, morphological noise cleaning, contour extraction, convex hull computation, and fingertip tracking.

1. RGB to HSV Skin Tone Segmentation
The HSV color space separates chromaticity (Hue) from illumination (Value). Skin pixels are filtered using peer-reviewed boundaries:
\[H \in [0^\circ, 28^\circ] \cup [335^\circ, 360^\circ], \quad S \in [35, 180], \quad V \in [50, 255]\]
2. Morphological Filtering (Opening & Closing)
Eliminates salt-and-pepper noise and bridges gaps in the binary palm mask:
\[\text{Erosion: } (A \ominus B)(x,y) = \min_{(i,j) \in B} A(x+i, y+j)\] \[\text{Dilation: } (A \oplus B)(x,y) = \max_{(i,j) \in B} A(x-i, y-j)\] \[\text{Opening: } A \circ B = (A \ominus B) \oplus B \quad (\text{noise suppression})\]
3. Slicing Collision Geometry: Line Segment to Circle
Computes whether blade segment \(P_1(x_1, y_1) \to P_2(x_2, y_2)\) cuts fruit circle \(C(x_c, y_c)\) of radius \(R\):
\[t = \operatorname{clamp}\left(\frac{(C - P_1) \cdot (P_2 - P_1)}{\|P_2 - P_1\|^2}, \; 0, \; 1\right)\] \[P_{\text{closest}} = P_1 + t(P_2 - P_1), \quad \text{Collision if } \|C - P_{\text{closest}}\| \le R\]
